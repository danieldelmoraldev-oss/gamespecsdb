You could install all of the games below and still use less space than a single sports game. See [why sports games are so big](/guides/why-are-switch-2-sports-games-so-big/).

## Small size and physical format

A small game on a **full cartridge** uses almost no storage at all, because it runs from the card. On a **Game-Key Card** or digital, it still downloads, but the download is small and quick. Either way, these games are the easiest to keep installed. Check each game's format on its page, or browse the [full cartridge list](/lists/full-cartridge-games/).
